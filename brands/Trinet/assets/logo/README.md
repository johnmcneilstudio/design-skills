# TriNet logo and campaign assets

This folder contains the approved TriNet raster wordmarks and the supplied `really` campaign lockup.

## Files

| File | Use | Notes |
|---|---|---|
| `Theme=Light.png` | Light or white backgrounds | TriNet Navy `#0B0134` wordmark with Logo Orange `#E14700` accent |
| `Theme=Dark.png` | Dark or navy backgrounds | White `#FFFFFF` wordmark with Logo Orange `#E14700` accent |
| `really-lockup.svg` | The word `really` within campaign headlines | Supplied vector artwork with its integrated orange underline |

The logo filenames describe the theme where each logo should be used, not the color of the wordmark.

## Logo usage

- Use `Theme=Light.png` on white and light neutral surfaces.
- Use `Theme=Dark.png` on navy, black and other dark surfaces.
- Preserve the original proportions and transparent background.
- Do not stretch, crop, redraw or recolor the wordmark.
- Do not rebuild the orange accent using the campaign orange. The supplied logo artwork uses `#E14700`.
- Maintain enough clear space and contrast for the complete wordmark to remain legible.

## `really` lockup usage

- Use `really-lockup.svg` whenever the campaign word `really` appears as the underlined subject in a headline.
- This lockup is the **only underlined element permitted in any banner, social post, motion frame, page or other design**.
- Do not underline any other word or element.
- Do not type `really` and add a separate rule beneath it; use the supplied lockup.
- Preserve the artwork and proportions. Do not redraw, stretch or separate the word from its underline.
- Size and optically align the lockup with the surrounding headline so it reads as part of the same sentence.

## File limitations

The two logo files are raster PNG exports. They are appropriate for standard web, presentation and screen use, but should not be enlarged for large-format or high-resolution print production. Request an approved vector logo master when vector output is required.

`really-lockup.svg` is vector artwork and should remain vector whenever the production format allows.
